# ScientificCalculator
Multi-mode calculator, does basic operations, advanced operations and grade calculation.

After launching choose one of three modes: <br>
-first mode does basics operations (+, -, *, /); <br>
-second mode does advanced operations (power, square root, percentage, trigonometry => sine, cosine, tangent); <br>
-third mode collects a series of numbers and calculates the average grade, insert numbers like this (2;4;5,45); <br>
 NB: if ',' doesn't work use '.' when entering doubles. <br>
